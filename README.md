# 🌟 Xclusive Labels

Xclusive Labels is a modern **shipping and payment management platform** designed to streamline operations for businesses while delivering real value to users. This full-stack project was built using Django and Django REST Framework, incorporating dynamic workflows, secure payments, and a powerful admin dashboard.

---

## 🚀 Project Overview

Xclusive Labels enables businesses to manage shipping labels, payments, coupons, referrals, and pricing in a seamless and user-friendly manner. The platform focuses on **security, scalability, and real-world usability**.

---

## 🧩 Tech Stack

- **Backend:** Django, Django REST Framework, Python  
- **Frontend:** HTML, CSS, Bootstrap, JavaScript, jQuery, AJAX  
- **Database:** SQLite/PostgreSQL (depending on deployment)  
- **Authentication:** Role-based access control, Two-Factor Authentication (2FA)  
- **Payment Integration:** PayPal  

---

## 🎯 Key Features

- 📦 **Dynamic Shipping Label Creation:** Generate labels for shipments quickly and efficiently  
- 💳 **PayPal Payment System:** Secure payment processing for orders  
- 🎟 **Coupon & Referral Management:** Enable discounts and commission tracking  
- 📉 **Smart Pricing Engine:** Calculate competitive prices based on real-time competitor rates  
- 🔐 **Role-Based Access Control:** Admin, user, and manager roles with 2FA for added security  
- 🛠 **Admin Dashboard:** Manage users, payments, operations, and reports from a centralized dashboard
